# Proyecto-Cine

Proyecto para digitalizar la administracion de asientos de un cine y evitar errores en las reservaciones.

## Integrantes
- Joselyn Olea
- Hector Valencia 

## Descripcion
Programa en consola que usa una matriz de 5 filas x 6 columnas para controlar los asientos del cine.
Cada asiento puede estar Libre (L) u Ocupado (O).

## Que hace?
1. Mostrar la matriz de asientos
2. Reservar asiento
3. Liberar asiento
4. Consultar disponibilidad
5. Contar ocupados y disponibles
6. Mostrar porcentaje de ocupacion

## Tecnologias utilizadas
- Lenguaje: C#
- Plataforma: .NET Console
- Control de versiones: Git y GitHub

## Como ejecutarlo?
1. Entrar a la carpeta CodigoFuente
2. Abrir el archivo Program.cs
3. Correr el programa
4. Elegir una opcion del menu del 1 al 6

- Evidencias: Capturas de pantalla
